# 🏢 Cloud-Based Leave Management System

A full-featured, cloud-ready web application for managing employee leave requests with real-time updates, admin controls, and notifications.

## 🚀 Live Demo
> Coming soon via GitHub Pages

## ✨ Features

### Employee
- 🔐 Login & Signup
- 📝 Apply for leave (Annual, Sick, Emergency, Casual, Unpaid)
- 📋 View leave history & status
- ❌ Cancel pending requests
- 🔔 Real-time notifications when leave is approved/rejected
- 👤 Profile page with leave summary

### Admin
- ⚙️ Approve or Reject employee leave requests
- 👥 View all registered employees
- 📊 Dashboard with full statistics
- 🔔 Notifications for new leave requests

## 🛠️ Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Storage:** LocalStorage (Firebase-ready architecture)
- **Design:** Responsive dark UI

## 🎯 How to Run

### Option 1 — Run Locally
1. Download `index.html`
2. Double-click to open in any browser
3. Done! No installation needed ✅

### Option 2 — Live via GitHub Pages
1. Fork this repository
2. Go to Settings → Pages
3. Select `main` branch
4. Your app is live! 🎉
